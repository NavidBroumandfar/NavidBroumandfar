# Navid

**NAVIDBR Applied AI Systems**

I work on applied AI systems where the hard part is not the model alone, but the
workflow, source shape, evaluation boundary, and path from public proof to a
working system.

Public site: [navidbr.me](https://navidbr.me)  
Work records: [navidbr.me/work](https://navidbr.me/work)

Core thesis: **AI ideas are easy. Working systems are harder.**

System path: **Business -> Systems -> Data -> AI -> Products**

## Current Focus

- Source preparation before retrieval or AI review
- Grounded document review with citations and escalation boundaries
- Behavior evaluation before agent authority expands
- ML product proof with explicit production limits
- Public proof records that state what is proven and what is not
