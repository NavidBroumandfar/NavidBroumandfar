I work on applied AI systems where the hard part is not the model alone, but the
workflow, source shape, evaluation boundary, and path from public proof to a
working system.

The website is the canonical public layer:

- [navidbr.me](https://navidbr.me) for identity, notes, and routing
- [navidbr.me/work](https://navidbr.me/work) for public Work records
- GitHub repositories for source evidence behind selected proof records

## Current Focus

| Layer | What I look for |
| --- | --- |
| Workflow | What repeated work, decision, or handoff actually needs support? |
| Source shape | What data, document, trace, or record must exist before AI can help? |
| Boundaries | What should the system refuse, escalate, or leave to a human? |
| Evaluation | What evidence shows the behavior is stable enough to trust? |
| Product path | What is proven, what is not proven, and what should happen next? |

## Working Pattern

```text
Business pressure
  -> workflow and owner
  -> source shape and constraints
  -> evaluation and boundaries
  -> AI or product surface
  -> public proof before product claims
```
